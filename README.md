# Annie Su Portfolio

Annie Su 的影像創作與視覺設計作品集，使用純 HTML、CSS、JavaScript 製作，適合直接部署到 GitHub Pages。

## GitHub Pages 部署

1. 將整個資料夾推送到 GitHub repository 的 `main` 分支。
2. 開啟 repository 的 **Settings > Pages**。
3. 在 **Build and deployment** 選擇 **Deploy from a branch**。
4. Branch 選擇 `main`，資料夾選擇 `/ (root)`，按下 **Save**。
5. 等待 GitHub Pages 完成部署後，使用頁面提供的網址開啟網站。

網站中的 YouTube 播放器使用公開 embed URL；若影片本身限制嵌入，瀏覽器會顯示 YouTube 提示，這是影片端權限設定造成的。
